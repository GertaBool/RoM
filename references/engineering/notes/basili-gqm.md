## Readings for our work
- Our rule of questions first, each with its source, matches GQM's top-down order: goal, then questions, then metrics, then data collection; a figure or tool that no question asks for is the bottom-up measurement GQM says will not work. Check: every registered figure and every tool names the question it answers, and every question names a goal (the mission's essential variables). Rests on: p. 2 (top-down; bottom-up will not work); p. 5 (questions, then measures, then collection mechanisms). Would not apply if: the work is exploratory description of a game, where GQM's goal step is the setup and whole-game questions themselves.
- Write each AI-change goal in GQM form (purpose, object, issue, viewpoint) and each prediction as the question plus the metric that answers it, e.g. purpose improve, object the AI's war decisions, issue win rate against fixed opponents, viewpoint the human player. Rests on: p. 3 (goal for an object, models of quality, viewpoints, environment); p. 4 (goal coordinates). Would not apply if: a prediction is about a formula result, which is computed, not measured.
- Include in every model a metric that tests the model itself (e.g. whether the harness reproduces known outcomes, whether a check catches planted errors), because GQM models need refinement and their reliability must be evaluated. Rests on: p. 7 (learning process factor). Would not apply if: the instrument has been validated separately and nothing in it has changed.
- Prefer existing reliable data (game logs, saves, XML records) over new instruments; build a new tool only when no existing source answers. Rests on: p. 7 (maximise use of existing data if available and reliable). Would not apply if: the existing source is known to be unreliable for that question (e.g. a save's state used for an earlier turn).
- Mark subjective measures (readings, judgements of play quality) as subjective and name the viewpoint; keep objective counts (units, turns, seeds) separate. Rests on: p. 3 (objective vs. subjective data); p. 4 (the same metric may differ by viewpoint). Would not apply if: no subjective judgement enters the result.
- The interpretation rules must be fixed before the data come in; this supports registering predictions before evidence. Rests on: p. 2 (rules for interpretation of measurement data); p. 8 (interpreted according to schemes previously defined). Would not apply if: the analysis is openly labelled exploratory.
- The paper gives no outcome evidence for GQM, only a list of adopting organisations; cite it for the structure of the method, not for its effectiveness. Rests on: p. 9 (applied in several organisations; no results reported). Would not apply if: the cited companion works report measured outcomes and are read.
